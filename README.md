📚 Syllabus Cracker

Syllabus Cracker is a web-based application that automatically converts academic syllabi into a structured and personalized study plan.
It helps students organize their preparation efficiently by breaking down topics and distributing them across available study days.

🎯 Problem Statement

Students often struggle to:

Understand long and unstructured syllabi

Decide what to study each day

Manage time efficiently before exams

Syllabus Cracker solves this by transforming syllabus documents into a clear, day-wise study schedule.

🚀 Features

Upload syllabus in PDF or TXT format

Automatic extraction of:

Units

Topics

Intelligent daily study plan generation

Adjustable:

Exam date

Study hours per day

Clean and simple user interface

Web-based (no installation required)

🛠️ Tech Stack

Programming Language: Python

Framework: Streamlit

Libraries Used:

pdfplumber (PDF text extraction)

Streamlit (UI & deployment)

🧠 How It Works

User uploads a syllabus file (PDF/TXT)

The system extracts text from the document

Units and topics are identified using rule-based parsing

The user selects:

Exam date

Available study hours per day

A personalized, date-wise study plan is generated automatically

▶️ Run Locally (Optional)

If you want to run the app on your own system:

pip install -r requirements.txt
streamlit run app.py
